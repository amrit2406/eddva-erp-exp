## 🚀 Current Application Flow

### Login Flow
1. User visits `/login`
2. Enters email and password
3. React Hook Form validates input using Zod schema
4. User clicks "Sign In"
5. useLogin hook calls loginApi (dummy implementation)
6. On success: tokens stored, auth state updated, navigate to `/dashboard`
7. On error: error message displayed

### Dashboard Flow
1. User is authenticated
2. DashboardPage component loads
3. useDashboard hook fetches data via TanStack Query
4. Displays:
   - Stat cards with trends
   - Attendance overview
   - Fee overview
   - Recent activities
5. User can navigate via sidebar
6. User can logout via user menu

### Protected Routes
- `/dashboard` - Protected (requires authentication)
- `/login` - Public (redirects to dashboard if authenticated)

## 📝 Development Notes

### How to Login
1. Visit: `http://localhost:5174/login`
2. Enter any valid email (e.g., `admin@school.edu`)
3. Enter any password (6+ characters, e.g., `password123`)
4. Click "Sign In"
5. You'll be redirected to `/dashboard`

### How to Logout
1. Click on user avatar in header
2. Click "Logout" in the dropdown
